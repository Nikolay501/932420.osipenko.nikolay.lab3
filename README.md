# Лабораторная работа №3: Вёрстка макета с помощью Flexbox и Grid

Выполнил: Осипенко Николай

## Описание работы
В рамках работы макет персональной страницы был доработан с применением Flexbox и CSS Grid, а также адаптирован под мобильные устройства и планшеты.

## Что реализовано:
1. **Навигация (Flexbox):**
   - Добавлено адаптивное горизонтальное меню в шапке сайта (`<nav>`).
   - На мобильных экранах пункты меню перестраиваются в колонку.

2. **Секция карточек (Flexbox):**
   - Блок «Наблюдаемые объекты» реализован на флексах.
   - Использованы семантические теги `<article>`.
   - Карточки адаптируются под ширину экрана (3 в ряд на десктопе, 2 на планшете, 1 на смартфонах).

3. **Дашборд / Галерея (CSS Grid):**
   - Сетка 3x2 для отображения астрономических данных.
   - На планшетах перестраивается в сетку 2x3, на мобильных устройствах — в 1 колонку.

4. **Адаптивность и доступность:**
   - Написаны медиа-запросы для брейкпоинтов 768px и 480px.
   - Проверено отсутствие горизонтального скролла на всех разрешениях.
   - Цветовая схема проверена на контрастность (соотношение текста к фону выше 4.5:1 по WCAG).

## Структура проекта
* `index.html` — основная разметка
* `style.css` — стили оформления, сетки и медиа-запросы
* `images/` — каталог с изображениями
